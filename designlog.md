## Concepts learnt

This project has taught me:
* How to use a datasheet to understand how a sensor like the DHT11 operates then to make a set of functions to read data incoming from it and translate it to an output
* How to use 8 bit register to send that data to the output such as the 4 digit 7 segment display
* The concept of refresh rate to output my data to the display without it flickering
* Implementation of checksum error detection for incoming DHT11 data
* How to convert bits in 7 segment display values

## Issues Encountered

* The datasheet for the DHT11 was difficult to understand using the diagrams and explanations and so took some time and debugging to get my functions to work
